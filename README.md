# 공유압 실습실 (Web Hydraulic · Pneumatic · Sequence Trainer)

브라우저에서 바로 사용하는 **공압 · 유압 · 전기 시퀀스 회로 작도 및 시뮬레이션** 교육용 웹 프로그램입니다.
V-AMT 같은 공유압 실습 프로그램의 구성(회로 작도실 + 가상 실습실 + 자격증 예제)을 참고하여 웹으로 독자 구현했습니다.

## 주요 기능

| 구분 | 내용 |
|---|---|
| **회로 작도실** | 부품 끌어다 놓기, 포트 클릭/드래그 배관·배선, 꺾임점, 배관 위 클릭 시 자동 분기점, 선분 드래그로 경로 조정, 회전·반전·복사·붙여넣기·실행취소, 확대/이동 |
| **공압** | 공급원, 서비스유닛(FRL), 단동/복동 실린더, 공압 모터, 3/2·5/2·5/3·2/2 밸브(누름버튼·레버·디텐트·롤러·솔레노이드·파일럿), 교축/일방향 유량제어, 체크, 셔틀(OR), 2압(AND), 급속배기, 시간지연 밸브, 압력계, 압력 스위치 |
| **유압** | 파워유닛, 펌프, 탱크, 필터, 어큐뮬레이터, 릴리프·감압·시퀀스·파일럿 체크·체크 밸브, 교축·일방향·압력보상 유량제어, 4/2·4/3(올포트블록/탠덤/오픈/플로트)·2/2 밸브, 복동/단동 실린더, 유압 모터 |
| **전기 (DC24V)** | +24V/0V, 푸시버튼 a/b, 유지형 스위치, 비상정지, 리밋 스위치 a/b, 근접센서, 압력스위치 접점, 릴레이 코일/접점, ON·OFF 딜레이 타이머, 카운터(+리셋), 솔레노이드, 램프, 부저 |
| **시뮬레이션** | 관로 압력 해석(절점 해석 + 비선형 밸브 액티브셋), 실린더/모터 운동, 릴리프 오버라이드, 미터인/아웃/블리드오프, 감압·시퀀스, 릴레이 자기유지·타이머·카운터 · 관로 압력 색 표시 · 통전 표시 · 실시간 파라미터 조정 · 속도 조절 · 단계 실행 |
| **가상 실습장비** | 작도한 회로가 실습 패널 위 모듈(실린더·밸브·파워유닛·전기 제어반)과 호스로 자동 배치되어 동일하게 동작, 장비 버튼 직접 조작 |
| **변위-시간 선도** | 실린더 변위와 솔레노이드·릴레이 동작 상태를 시간축으로 표시 |
| **예제·과제** | 공유압기능사·설비보전기사 실기 유형 26종 (공압 7, 전기-공압 8, 유압 8, 전기-유압 3) |
| **저장** | 브라우저 자동 저장(이어서 하기), JSON 저장/열기, SVG·PNG 내보내기, 인쇄 |

## 태그 연결 규칙
- 솔레노이드 코일 `Y1` ↔ 밸브 속성의 솔레노이드 `Y1`
- 리밋 스위치·근접센서 `LS1`, 롤러 밸브 `1S1` ↔ 실린더 속성의 후진끝/전진끝/중간 센서 태그
- 릴레이 코일 `R1` ↔ 릴레이 접점 `R1`, 타이머 `T1`, 카운터 `C1`, 압력 스위치 `PS1`

## 실행
정적 웹앱이라 빌드가 필요 없습니다.

```bash
npx serve .            # 또는 python3 -m http.server
```

## 테스트
```bash
npm test               # 엔진 단위 테스트 + 26개 예제 동작 검증
npm run test:e2e       # Playwright 브라우저 E2E (playwright 전역 설치 필요)
```

## 구조
```
index.html, css/app.css
js/components.js   부품 정의(기호·포트·속성·시뮬레이션 동작)
js/sim.js          시뮬레이션 엔진(유체 절점 해석 + 전기 시퀀스)
js/editor.js       회로 작도 캔버스
js/trainer.js      가상 실습장비 뷰
js/chart.js        변위-시간 선도
js/examples.js     예제·과제 회로
js/main.js         메뉴·툴바·팔레트·속성창·파일
```

> 교육용 독자 구현이며 특정 상용 소프트웨어의 코드·이미지 등 자산을 사용하지 않았습니다. 기호는 ISO 1219 / KS B 0054를 교육용으로 단순화했고, 수치는 교육용 근사 모델입니다.
