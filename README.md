# 유압 시퀀스 시뮬레이터

유압제어 실습과제 1·2·3의 유압 회로도와 릴레이(래더) 전기 회로도를 그대로 옮겨,
PB1 → 릴레이 → 솔레노이드 → 밸브 → 실린더 → 리밋 스위치로 이어지는 동작을 단계별로 보여주는 학습용 웹 시뮬레이터.

- `index.html` – 페이지 셸 (홈 / 기초 원리 / 과제 1·2·3 / 부품 사전)
- `js/hyd.js` – 유압 기호(ISO 1219 스타일) SVG + 상태 애니메이션
- `js/ladder.js` – 래더 회로도, 접점 개폐·전류 경로 표시
- `js/sim.js` – 시뮬레이션 엔진(릴레이 지연, 밸브 전환, 단계 판별) + 과제 화면
- `js/tasks.js` – 과제별 회로, 유압 흐름 계산, 단계 설명, 퀴즈
- `js/parts.js`, `js/basics.js` – 부품 사전, 기초 원리 미니 실습
- `js/studydata.js`, `js/study.js` – 암기 훈련(회로도·노트 빈칸 타이핑, 3단계 필사, 순서 맞추기, 간격 반복 복습, 오답 노트, 모의고사)

빌드 과정 없는 정적 사이트라 `index.html`을 바로 열거나 Vercel 등에 그대로 배포하면 됩니다.
